# 40 Days of JavaScript
 
My notes, exercises and projects from the [40 Days of JavaScript](https://github.com/tapascript/40-days-of-javascript) course by Tapas Adhikary on his YouTube channel, [tapaScript](https://youtube.com/tapasadhikary).
 
## Modules
 
| Module | Days | Topics |
| --- | --- | --- |
| [01 Introduction to JS](Module%2001%20-%20Introduction%20to%20JS) | 1 to 7 | Variables, operators, control flow, loops, functions |
| [02 Foundational JS](Module%2002%20-%20Foundational%20JS) | 8 to 16 | Execution context, hoisting and the TDZ, scope chain, closures, objects, `this`, errors, arrays, debugging |
| [03 DOM](Module%2003%20-%20DOM) | 17 to 21 | Selecting and changing the DOM, events, advanced DOM tricks |
| [04 Async JS](Module%2004%20-%20Async%20JS) | 22 to 28 | Callbacks, promises, async/await, fetch, common mistakes, the event loop |
| [05 OOP](Module%2005%20-%20OOP) | 29 to 35 | Classes, prototypes and patterns, modules, Maps and Sets, debugging |
| [06 Advanced Concepts](Module%2006%20-%20Advanced%20Concepts%20in%20JS) | 36 to 39 | Debouncing, throttling, memoization, Web APIs, memory management, interviews |
 
## Projects
 
- **Rock Paper Scissors** (Day 7): first in the console, then on the DOM
- **Secret Number Game** (Day 7)
- **Quiz Game** (Day 21): a quiz app that loads real AIBE past papers from JSON. This was the first version of **[Help Me Practice](https://helpmepractice.online)**, which now covers 15 exams.
## Running the projects
 
Open a project's `index.html` in a browser. Notes files are plain `.js` and can be run with Node.js: `node "<file>.js"`.
